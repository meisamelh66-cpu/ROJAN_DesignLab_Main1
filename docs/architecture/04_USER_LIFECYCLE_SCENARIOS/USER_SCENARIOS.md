# User Lifecycle Scenarios

## Owner

ثبت نام Website → OTP → ایجاد Salon → مالکیت Backend → دانلود Desktop →
ورود → مدیریت

## Specialist

Invitation → Accept → OTP → Membership Active → Permission Resolution

## Customer

QR → Application → Identity → Salon Context → Booking

## Failure Scenarios

-   حذف دسترسی
-   انتقال مالکیت
-   خروج عضو
-   تغییر شعبه باید توسط Backend مدیریت شود.
